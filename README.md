# site-pnlir

Site du Programme National de Lutte contre l’Insuffisance Rénale (PNLIR),
Ministère de la Santé et de la Population, République du Congo.

En ligne : https://pnlir.cg/

## Fichiers

- `index.html` : le site
- `apercu-pnlir.png` : image affichée lors des partages (WhatsApp, Facebook…)
- `PNLIR_Decret_2019-225.pdf` et `PNLIR_Plan_Travail_Annuel_2026.pdf` : documents de la rubrique Ressources
- `favicon.ico`, `favicon-192.png`, `apple-touch-icon.png`, `logo-pnlir.png` : icônes et logo
- `robots.txt`, `sitemap.xml` : fichiers pour les moteurs de recherche

## Mise à jour

Le dépôt est relié à l’hébergeur : chaque modification est publiée automatiquement.

Pour modifier le site, utiliser **Add file > Upload files** et déposer le nouveau
`index.html` (le fichier est trop lourd pour l’éditeur en ligne).
